# RE-ZERO V4.4 TRADER

Infrastructure d'analyse de marché et d'aide à la décision. RE-ZERO n'est ni un oracle ni un système garantissant des gains.

## Principes
INTÉGRITÉ > QUALITÉ > RISQUE > FRÉQUENCE. Les proxies sont signalés, les données inconnues ne deviennent jamais des faits et tout hard gate échoué impose PAS DE TRADE.

## V4.4
Renforcement du Truth Layer, Data Quality/Freshness, Decision Gates, Risk Engine, Decision History, Execution Quality, System State, validation LLM et fondation Drift Detection. Le projet conserve les composants V4.3 fonctionnels.
